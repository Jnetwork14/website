  1. 01 / Write

    Plain code

    HTML, CSS and a little JavaScript. Colours and fonts live in one tokens file.

  2. 02 / Store

    Push to GitHub

    Each change is a commit on the main branch, so every version is saved and can be undone.

  3. 03 / Build

    GitHub Actions

    A workflow named Deploy to GitHub Pages runs on every push and packages the site.

  4. 04 / Live

    GitHub Pages

    The packaged site is served at jnetwork14.github.io/website.
